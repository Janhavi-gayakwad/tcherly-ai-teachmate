# Retrieval practice at the start of the next class
summary: Begin the next session with a few low-stakes questions that make students recall the difficult material.
helps_with: following up a difficult video segment in a flipped or blended course; consolidating key ideas
source: Roediger, H. L. & Karpicke, J. D. (2006). Test-enhanced learning: Taking memory tests improves long-term retention. Psychological Science, 17(3).

## When it can help
Roediger and Karpicke showed that practising recall (the testing effect) improves long-term retention more than re-studying the same material.

## Try it
Open the next live class with a few quick questions on the segment where Difficult clicks peaked, then discuss the answers.

## How to tell if it helped
The answers show which ideas are still shaky; on the next related video, Difficult clicks on those ideas should fall.
