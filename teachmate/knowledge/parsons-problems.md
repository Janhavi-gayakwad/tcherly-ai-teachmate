# Parsons problems
summary: Give students the lines of a correct program in jumbled order and ask them to arrange them.
helps_with: in-class practice after a programming demonstration; students who understand the idea but struggle with syntax or structure
source: Parsons, D. & Haden, P. (2006). Parson's programming puzzles: A fun and effective learning tool for first programming courses. Proceedings of the Australasian Computing Education Conference (ACE 2006).

## When it can help
Parsons problems let students practise program structure and logic without getting stuck on typing and syntax errors, which suits a quick in-class activity.

## Try it
Take the program from the difficult segment, split it into lines (optionally with one or two distractor lines) and have pairs put it in order, then discuss why.

## How to tell if it helped
Most pairs should reach the correct order quickly; the common wrong orders show which part of the logic to revisit.
