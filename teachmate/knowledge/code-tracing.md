# Trace code step by step with a variable table
summary: Execute code by hand (or with a visualiser), recording each variable's value after every step.
helps_with: programming demonstrations where students "could not follow the loop logic"; reasons "Too fast" or "Not enough explanation / examples" during live coding; students re-watching a demonstration
source: Lister, R. et al. (2004). A multi-national study of reading and tracing skills in novice programmers. ACM SIGCSE Bulletin, 36(4); Guo, P. J. (2013). Online Python Tutor: Embeddable web-based program visualization for CS education. Proceedings of ACM SIGCSE 2013.

## When it can help
Lister and colleagues found that many novice programmers struggle to trace what code does, which limits their ability to write it. Visualisers such as Online Python Tutor show each step of execution.

## Try it
Before running a program with loops or arrays, trace the first iterations on the board or in a visualiser, filling a table of variable values. Zoom in so the code is readable.

## How to tell if it helped
In the demonstration segment, "Too fast" and "Not enough explanation / examples" should fall, and fewer students should jump back to re-watch it.
